# Blog Website using React.js

This is a Blog website built using React.js. It allows users to view, add, edit, and delete blog posts. The website is responsive, modern, and interactive.

## Live Demo: https://thecodetimes.netlify.app/

## Features
▫ Home Page: Displays a list of blog posts with title and brief content preview.

▫ Single Post View: Each blog post can be clicked to view in detail.

▫ Add Post: Users can add new blog posts with a title, content, and author name.

▫ Edit Post: Existing posts can be edited.

▫ Delete Post: Users can delete blog posts.

▫ Responsive Design: The website is fully responsive and works well on mobile, tablet, and desktop devices.

▫ React Router: Used for navigation between pages (home, add post, view post).

▫ State Management: Uses React's built-in hooks (useState, useEffect) for managing state and lifecycle methods.

## Technologies Used
▫ React.js: JavaScript library for building user interfaces.

▫ React Router: Used for handling page navigation and routing.

▫ Tailwind CSS: A utility-first CSS framework used for styling the website.

▫ Local Storage/Backend: Depending on your implementation, you may use local storage or connect the website to a backend to persist the blog posts.
